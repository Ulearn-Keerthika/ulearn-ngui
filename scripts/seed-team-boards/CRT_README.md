# ULearn CRT Platform — Team A

**Tool:** GitHub Issues + Milestones (free forever)  
**Permission gate in ULearn:** `crt.access` (label: Allowed CRT)

## Team
2 members. Split work using labels:
- `role/frontend` — Angular UI
- `role/backend` — Supabase schema, RLS, edge functions
- `role/shared` — both

## How to work
1. Open **Issues** → filter by Milestone (Phase 0 → Phase 6)
2. Assign yourself an issue
3. Move mentally: Open → In progress (assignee) → Done (close with PR link)
4. Every issue has **Expected output** — that is the acceptance bar

## Out of scope (Team B owns)
AI mock interviews, voice interviewer, interview rubrics, interview quotas.

## ULearn dependency
Students only see CRT if they have Allowed CRT. Do not rebuild Auth or Labels admin.
