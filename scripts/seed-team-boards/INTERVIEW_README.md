# ULearn AI Mock Interview — Team B

**Tool:** GitHub Issues + Milestones (free forever)  
**Permission gate in ULearn:** `interview.access` (label: Allowed Interview)

## Team
2 members. Split work using labels:
- `role/frontend` — Angular UI
- `role/backend` — Supabase, edge functions, quotas
- `role/ai` — prompts, rubrics, model provider
- `role/shared` — both

## How to work
1. Open **Issues** → filter by Milestone (Phase 0 → Phase 6)
2. Assign yourself an issue
3. Close only when **Expected output** is met
4. Never put AI API keys in the frontend

## Out of scope (Team A owns)
CRT syllabus, aptitude banks, company CRT packs, CRT readiness formula.

## ULearn dependency
Students only see Interview if they have Allowed Interview. Reuse profile/college/batch IDs from ULearn.
